# NYFW Style — кликабельный веб-прототип (дизайн)

Дата: 2026-10-29

## Зачем

Заказчик прислал ТЗ на MVP «NYFW Style» (AI fashion advisor) и ждёт коммерческое
предложение. Прототип показываем заказчикам вместе с предложением: он должен
выглядеть как готовое приложение в их концепции Luxury Editorial и давать
«прожить» ключевые сценарии ТЗ. Экспо-приложение — позже, если проект возьмём.

## Цели

- Красиво: визуал на уровне их мокапа (ivory / чёрный / champagne,
  Playfair Display + Inter, крупные editorial-фото, много воздуха).
- Открывается по ссылке у кого угодно, без установки.
- На телефоне — как приложение во весь экран (можно «На экран Домой»);
  на компьютере — приложение в рамке iPhone по центру (для показа на звонке).
- Все кнопки ведут куда-то; сценарии из критериев приёмки ТЗ проходятся до конца.

## Не цели

- Никакой оплаты, реального AI, бэкенда, авторизации, CMS/админки.
- Не Expo/React Native на этом этапе.
- Не копируем код AI Stylist 1-в-1; берём только идеи.

## Анти-цели (провал, даже если работает)

- Выглядит как шаблон / «сайт», а не как премиальное приложение.
- Кнопки-пустышки на показе.
- Фото показов, взятые с чужих сайтов, или выдуманные «реальные» цены/магазины,
  выдаваемые за настоящие.

## Ограничения

- Бренд NYFW используется только внутри демо (как в их концепте); страница
  закрыта от индексации (`noindex`), ссылка не публикуется открыто.
- Изображения — только со свободной лицензией (Unsplash) или плейсхолдеры.
- Товары и цены — явно демо-данные; affiliate-ссылки помечены.
- Язык интерфейса — английский.

## Подходы (рассмотрено)

1. Expo + веб-сборка из того же кода — отложено: пользователь решил, что Expo рано.
2. Статичные макеты без навигации — отклонено: на показе видно, что ничего не работает.
3. **Веб-прототип (выбран):** отдельное веб-приложение, мобильный layout,
   полноценная навигация и мок-«AI».

## Решения (мои, можно поправить)

- Стек: Vite + React + TypeScript, react-router, CSS-модули/переменные-токены;
  анимации — Framer Motion. Слой данных через интерфейсы (`content`, `stylist`,
  `trips`) с mock-реализацией — при переходе на реальный продукт меняется только он.
- Репозиторий: новый приватный `nyfw-style` на том же GitHub-аккаунте.
- Хостинг: существующий VPS (nginx) на отдельном поддомене, HTTPS.
- Состояние демо (имя из онбординга, сохранённые образы, чек-лист поездки)
  хранится в localStorage, есть «Reset demo» в профиле.
- «AI»-ответ: задержка ~1.5 с со скелетоном/анимацией «styling…», затем образы
  из заранее подготовленного набора, подобранные по введённым параметрам;
  Regenerate показывает другой вариант.
- Погода: только в Pack My Trip (мок-прогноз по направлению + ручной ввод
  температуры). Отдельного погодного блока на главной нет.
- Нижняя навигация: Home / Style / Closet / Shop / You (как в мокапе).

## Экраны

| Экран | Содержание |
|---|---|
| Welcome / Onboarding | Splash с логотипом → Apple / Google / Email / Continue as guest (кнопки ведут дальше без реального входа) → 4–5 шагов: стиль, бюджет, бренды, сценарии, согласие на геолокацию/фото |
| Home | Hero-фото, «Welcome, {name}», карточки What to Wear Today, Pack My Trip, Trend Report, Designers to Watch, Saved looks |
| Style → What to Wear Today | Форма (событие, стиль, бюджет, пожелания) → 2–4 образа: коллаж, объяснение, список вещей, альтернативы, Save / Regenerate / Shop Similar |
| Pack My Trip | Направление, даты, цель, dress codes, багаж → капсула → образы по дням → checklist с отметками, удаление/замена вещи, «missing items»; пометка «не основано на гардеробе», если Closet пуст |
| Trend Report | Фид трендов (сезон, фильтры) → карточка тренда → «From Runway to Real Life» с учётом профиля |
| Designers | Список → карточка дизайнера/коллекции с тегами трендов |
| Shop | Каталог товаров (цена, валюта, партнёр, метка Affiliate) → карточка → «Open in partner store» (демо-модалка) |
| Closet (Wardrobe Lite) | Сетка вещей по категориям, добавление вещи (фото/категория/цвет), сохранённые образы |
| You (Profile) | Профиль, стиль, согласия, избранное, экспорт/удаление данных (демо), Reset demo |

## Остаётся на исполнителя

Точная вёрстка, микроанимации, подбор фото, тексты демо-контента
(8–10 трендов, 6–8 дизайнеров, ~30 товаров, ~12 образов).
